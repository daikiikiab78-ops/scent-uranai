# SCENT 生まれ日占い（お客さま向け・公開用）

作成日：2026年10月17日

## これは何？
SCENTのオリジナル占いアプリです。生年月日から、性格・運気・相性・カルテ（1枚の結果画像）・キャラクター一覧が見られます。
スマホの「ホーム画面に追加」で、アプリのように置いて使えます（PWA）。

- 入力した生年月日・名前は、スマホの中で計算するだけです。どこにも送信・保存しません。
- 外部との通信は、文字の書体（Google Fonts）の読み込みだけです。アクセス解析・広告はありません。
- 一度開くと、電波がなくても開けます（書体だけは、読み込めないときスマホ標準の書体になります）。

## ファイル
- `index.html` … アプリ本体
- `manifest.webmanifest` … ホーム画面に置くための設定（名前・色・アイコン）
- `sw.js` … 電波がなくても開くための仕組み
- `icons/` … アイコン画像（192・512・マスク対応512・iPhone用180）
- `.nojekyll` … GitHub Pages に「そのまま公開して」と伝える空ファイル

## 公開のしかた（GitHub Pages）
1. このフォルダの中身を、GitHub のリポジトリの一番上の階層に置いて push します。
2. GitHub のリポジトリで Settings → Pages を開き、Branch を `main`（フォルダは `/ (root)`）にして Save します。
3. 数分後に出る `https://（ユーザー名）.github.io/（リポジトリ名）/` が公開アドレスです。QRコードにして店頭に置くと便利です。

※ ホーム画面に追加できるのは https のアドレスだけです（GitHub Pages は https なので大丈夫です）。

## 更新のしかた
1. `index.html` などを直します。
2. `sw.js` の一番上にある `var VERSION = 'v1';` の数字を上げます（例：`v2`）。
3. push します。お客さまのスマホには、次に開いたときに新しい版が反映されます。

## お客さまへの案内（画面の下にも載っています）
- iPhone：Safariで開く → 共有ボタン → 「ホーム画面に追加」
- Android：Chromeで開く → メニュー → 「ホーム画面に追加」または「アプリをインストール」

## 注意
エンターテインメントとして楽しむ占いです。点数は四柱推命の考え方にもとづいて計算したもので、科学的な裏づけはありません。
